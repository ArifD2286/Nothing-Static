# Nothing Static


A game where you take down targets with bouncy bullets! Dodge any bullets that bounces back to you or you could get hit and it would be game over for you ;_;

### Controls:
- Use [ A, D ] to move
- Mouse [ Left button ] to shoot
- [ R ] to quickly reset the game and play again if you win or loose.

### How to play:
- Aim at targets to take them down
- Dodge any incoming bullets
- Get the best time possible by taking down all the targets!
